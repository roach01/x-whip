# X / WHIP

上班摸鱼，记得刷 X。
他催你关注、发帖、回复。你点他一下，留一笔。
你开着，他就一直催。

一只待在 Windows 桌面上的马斯克大头火柴人，陪你带薪刷 X。默认十五分钟提醒你去 X 看看，别光刷，也记得关注、发帖、回复。到点开始抽鞭，越不理他，场面越不讲道理。

## 怎么用

安装后打开 X / WHIP。刷过 X，左键点他：今日记录 +1，留下一次手动记录，收鞭，重新冷却。拖动只负责搬家，不记次数。

右键有设置、试抽、重新计时、去 X。卡皮芭拉好友入口和对应台词可在设置里一起关闭。

头上平时没字。闲逛二十到四十秒偶尔说一句，几秒后消失；抽鞭时也有讲话间隔。十六种照片表情都来自同一张基准照片，发型和打光保持一致。

## 越来越不像话

冷却分摸鱼、盯人、催促、蓄力四段。到点后每三抽升一级，总共六级。

| 暴躁级别 | 每抽间隔 |
| --- | --- |
| 1 | 3.2 秒 |
| 2 | 2.8 秒 |
| 3 | 2.4 秒 |
| 4 | 2.1 秒 |
| 5 | 1.8 秒 |
| 6 | 1.55 秒 |

鞭子只有一根。事故不止一种。v0.6.0 的八组动作轮换：后肩甩、弓步横抽、双手劈下、跺脚催促、反抽自己、被鞭子拽跳、被鞭子吊起甩到 X 牌、脚被缠住跳一下。

每一抽都有蓄力、甩出、回弹和停顿。身体关节配合分段绳运动，鞭子沿单根连续轨迹甩动；真人照片独立轻转，保持原比例。笑点穿插在反抽、缠脚和收鞭的停顿里。

四至六级让当前前台窗口短暂移位并还原，不使用桌面截图覆盖层；设置里可以关掉抖动。

抽鞭音效是本项目合成的挥鞭风声与短脆啪声，默认静音，可在设置里打开。

## 他嘴里的离谱指标

- 今天关注到400了吗？
- 今天发帖到200了吗？
- 今天互动到1500了吗？
- 今天交到好朋友了吗？
- 今天追热点了吗？
- 今天看“淡定的卡皮芭拉”首页了吗？（推广关闭后不出现）

这些数字是他的嘴硬，不是你要交的 KPI。点击计数由你手动确认，程序不连接 X 账号，也不判断你实际做了什么。当前桌面版记录当天总次数，每天北京时间零点清零，退出再开还记得今天的数字。

## 开着就催

只有冷却和抽鞭两个状态。默认十五分钟一轮，可设 1–180 分钟。到点抽鞭，点他一下记一笔、重新冷却，再到点再抽。退出应用才停止提醒。

官网有关注、发帖、回复三类手动试玩按钮和最近三笔小票。网页试玩刷新归零，与桌面应用数据独立；它们不会在 X 上执行任何动作。桌面版只记录每日总次数。

## 安装与更新

v0.6.0 Release 提供 `XWhipSetup-0.6.0.exe` 安装包和 `XWhip-Portable-0.6.0.zip` 免安装包。安装到当前用户目录，无需管理员权限。更新前右键退出旧宠物。

设置与每日计数保存在 `%LOCALAPPDATA%\XWhipPet\`，卸载后保留。安装包尚未配置代码签名证书。

## 自己编译

Windows 自带 .NET Framework 编译器即可编译，无需 NuGet。

```powershell
./scripts/build.ps1
./scripts/test.ps1
./scripts/package.ps1 -Iscc '你的 Inno Setup 6/ISCC.exe'
```

main 分支和 PR 自动编译、测试并生成安装包；推送 `v*` 标签自动发布 Release；介绍页使用 GitHub Actions 部署到 Pages。

抽鞭灵感来自 [OpenWhip](https://github.com/GitFrog1111/OpenWhip)。X / WHIP 的动作编排与绳索实现由本项目自行编写，未复制原作源码。
